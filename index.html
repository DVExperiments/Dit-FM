Welcome to DIT/FM

A fictional continuous radio station where DJs talk, songs play, and station IDs transmit exclusively through Morse code. No speech files, microphone, servers, or external audio services are required.

Hosts use separate pitches: DOT (530 Hz), DASH (760 Hz), and ECHO (950 Hz). Each track has its own tone profile. Broadcast audio is generated live with Web Audio.

Standard timings: dot = 1 unit, dash = 3, within-letter gap = 1, letter gap = 3, word gap = 7. WPM changes apply at the next Morse element.

Reality check: GitHub Pages is static hosting. The station runs continuously while the page is open; different visitors won't automatically hear the same time-synchronised broadcast. That can be added in a later version.

The 28 song titles and artists are catalogue metadata only until you supply Morse. For public release, only publish lyrics/Morse transcriptions you have permission to use. Converting copyrighted lyrics to Morse doesn't eliminate their copyright.

Broadcast clock

Rotation: host banter → station ID → songs → repeats. Only tracks with Morse code join the rotation. Official catalogue entries awaiting code will not broadcast.
